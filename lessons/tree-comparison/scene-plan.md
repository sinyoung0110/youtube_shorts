# 장면표

| 장면 | 화면 구성 | 검산 포인트 |
| --- | --- | --- |
| 1. 동기 | BST는 순서 규칙만 지키며 단순하게 넣고 찾습니다. AVL은 그 순서에 높이 균형 규칙을 더해 최악의 탐색 속도를 보장합니다. | 둘 다 이진 탐색 순서 유지 |
| 2. 예시 | 같은 값 10, 20, 30 삽입 · 단계별 강조 | AVL: 불균형 감지 |
| 3. 코드 | BST: left < node < right | 둘 다 이진 탐색 순서 유지 |
| 4. 정리 | BST 평균 O(log n), 최악 O(n) · AVL 최악 O(log n) · AVL은 갱신마다 높이 관리와 회전 비용 | BST 평균 O(log n), 최악 O(n) · AVL 최악 O(log n) |
