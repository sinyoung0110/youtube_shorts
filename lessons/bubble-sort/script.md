# 버블 정렬 — 대본 및 검산

- 대상: 처음 배우는 알고리즘 학습자
- 영상 길이: 약 49초
- 핵심 질문: 이웃끼리 바꾸면 큰 값이 어디로 갈까?

## 왜 필요한가

가까운 원소를 차례로 비교·교환해 큰 값을 끝으로 밀어냅니다. 동작이 단순해 학습에는 좋지만 큰 입력에는 비효율적입니다.

## 예시와 단계

입력: `[5, 1, 4, 2]`

1. 5와 1 교환 → [1,5,4,2]
2. 5와 4, 이어서 5와 2 교환
3. 첫 바퀴 끝 → [1,4,2,5]

## 특징

- 전제: 인접한 두 값을 비교해 큰 값을 오른쪽으로
- 시간: 최선 O(n)¹ · 평균·최악 O(n²)
- 공간/안정성: 추가 공간 O(1) · 안정 정렬
- 장점: 구현이 쉽고 거의 정렬된 데이터에서 조기 종료 가능
- 한계: 비교와 이동이 많아 큰 입력에 느림

## 핵심 의사코드

```text
for end in range(n - 1, 0, -1):
    swapped = False
    for i in range(end):
        if A[i] > A[i + 1]:
            A[i], A[i+1] = A[i+1], A[i]
            swapped = True
    if not swapped: break
```

## 내레이션 및 장면표

| 구간 | 내레이션 | 화면 |
| 00.0–11.7s | 정렬이 필요한데 원리가 궁금하다면 이웃한 두 값만 비교해 보세요. 버블 정렬은 큰 값을 오른쪽 끝으로 한 칸씩 밀어 보내는 가장 단순한 비교 정렬입니다. | 왜 필요한가 |
| 12.0–23.4s | 5, 1, 4, 2에서 5와 1을 바꾸고, 5와 4를 바꾸고, 5와 2도 바꾸면 첫 바퀴 끝에서 가장 큰 5가 맨 오른쪽에 놓입니다. | 숫자 예시 |
| 23.7–35.5s | 안쪽 반복문은 이웃한 A[i]와 A[i+1]을 비교합니다. 왼쪽이 더 크면 두 값을 바꾸고, 바뀐 적이 없으면 이미 정렬되어 반복을 멈출 수 있습니다. | 핵심 코드 |
| 35.8–48.3s | 일반적인 버블 정렬은 평균과 최악이 O(n²)라 큰 데이터에는 느립니다. 교환이 없는 바퀴를 감지하면 최선은 O(n)이 되고, 같은 값의 순서는 유지되는 안정 정렬입니다. | 복잡도와 선택 기준 |

검산 주의: ¹ swapped 플래그를 둔 최적화 버전 기준.
