# 장면표

| 장면 | 화면 구성 | 검산 포인트 |
| --- | --- | --- |
| 1. 동기 | 가까운 원소를 차례로 비교·교환해 큰 값을 끝으로 밀어냅니다. 동작이 단순해 학습에는 좋지만 큰 입력에는 비효율적입니다. | 인접한 두 값을 비교해 큰 값을 오른쪽으로 · 조기 종료 최적화 없음 |
| 2. 예시 | [5, 1, 4, 2] · 단계별 강조 | 5와 4, 이어서 5와 2 교환 |
| 3. 코드 | for end in range(n - 1, 0, -1): | 인접한 두 값을 비교해 큰 값을 오른쪽으로 · 조기 종료 최적화 없음 |
| 4. 정리 | 기본 구현: 최선·평균·최악 Θ(n²) · 정렬된 입력도 비교를 계속해 큰 입력에 비효율적 | 기본 구현: 최선·평균·최악 Θ(n²) |
