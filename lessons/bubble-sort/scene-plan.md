# 장면표

| 장면 | 화면 구성 | 검산 포인트 |
| --- | --- | --- |
| 1. 동기 | 가까운 원소를 차례로 비교·교환해 큰 값을 끝으로 밀어냅니다. 동작이 단순해 학습에는 좋지만 큰 입력에는 비효율적입니다. | 인접한 두 값을 비교해 큰 값을 오른쪽으로 |
| 2. 예시 | [5, 1, 4, 2] · 단계별 강조 | 5와 4, 이어서 5와 2 교환 |
| 3. 코드 | for end in range(n - 1, 0, -1): | 인접한 두 값을 비교해 큰 값을 오른쪽으로 |
| 4. 정리 | 최선 O(n)¹ · 평균·최악 O(n²) · 비교와 이동이 많아 큰 입력에 느림 | 최선 O(n)¹ · 평균·최악 O(n²) |
