# 장면표

| 장면 | 화면 구성 | 검산 포인트 |
| --- | --- | --- |
| 1. 동기 | 숫자 전체를 비교하는 대신 낮은 자리부터 각 자릿수로 안정 정렬합니다. 자릿수와 기수가 제한된 키에 효과적입니다. | 자리 수 d와 기수 b가 제한된 키 · 자릿수별 안정 정렬 |
| 2. 예시 | [21, 13, 12, 23] · 단계별 강조 | 십의 자리 안정 정렬 |
| 3. 코드 | exp = 1 | 자리 수 d와 기수 b가 제한된 키 · 자릿수별 안정 정렬 |
| 4. 정리 | 시간 O(d(n + b)) · 일반 객체 비교에는 바로 적용하기 어렵고 보조 공간 필요 | 시간 O(d(n + b)) |
