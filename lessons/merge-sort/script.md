# 병합 정렬 — 대본 및 검산

- 대상: 처음 배우는 알고리즘 학습자
- 영상 길이: 약 43초
- 핵심 질문: 작게 나눠 정렬한 뒤 합치면?

## 왜 필요한가

문제를 반으로 쪼개 정렬하고 두 정렬 구간을 합칩니다. 입력 모양에 관계없이 성능이 일정하고 안정적입니다.

## 예시와 단계

입력: `[4, 1, 3, 2]`

1. [4,1] → [1,4]
2. [3,2] → [2,3]
3. 두 정렬 구간 병합 → [1,2,3,4]

## 특징

- 전제: 분할 후 작은 정렬 결과를 순서대로 병합
- 시간: 최선·평균·최악 O(n log n)
- 공간/안정성: 배열 병합 추가 공간 O(n) · 안정 정렬
- 장점: 안정적이고 최악 시간 보장
- 한계: 배열에 합칠 임시 공간 필요

## 핵심 의사코드

```text
def merge_sort(A):
    if len(A) <= 1: return A
    mid = len(A) // 2
    L = merge_sort(A[:mid])
    R = merge_sort(A[mid:])
    return merge(L, R)
```
