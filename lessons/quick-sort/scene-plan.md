# 장면표

| 장면 | 화면 구성 | 검산 포인트 |
| --- | --- | --- |
| 1. 동기 | 기준값 pivot으로 배열을 두 편으로 분할하고 각 편을 재귀 정렬합니다. 평균적으로 빠르지만 분할이 한쪽으로 몰리면 느려집니다. | pivot 기준 분할 후 양쪽 구간 재귀 정렬 |
| 2. 예시 | [6, 3, 8, 2, 5] · pivot=5 · 단계별 강조 | pivot 5를 가운데 위치로 |
| 3. 코드 | pivot = A[hi] | pivot 기준 분할 후 양쪽 구간 재귀 정렬 |
| 4. 정리 | 평균 O(n log n) · 최악 O(n²) · 나쁜 pivot 선택은 최악 시간과 깊은 재귀 | 평균 O(n log n) · 최악 O(n²) |
