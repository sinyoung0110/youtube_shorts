# 퀵 정렬 — 대본 및 검산

- 대상: 처음 배우는 알고리즘 학습자
- 영상 길이: 약 47초
- 핵심 질문: 기준 하나로 작은 값·큰 값을 나누면?

## 왜 필요한가

기준값 pivot으로 배열을 두 편으로 분할하고 각 편을 재귀 정렬합니다. 평균적으로 빠르지만 분할이 한쪽으로 몰리면 느려집니다.

## 예시와 단계

입력: `[6, 3, 8, 2, 5] · pivot=5`

1. 5보다 작은 쪽 [3,2]
2. pivot 5를 가운데 위치로
3. 큰 쪽 [6,8] → [2,3,5,6,8]

## 특징

- 전제: pivot 기준 분할 후 양쪽 구간 재귀 정렬
- 시간: 평균 O(n log n) · 최악 O(n²)
- 공간/안정성: 분할 재귀 스택 평균 O(log n) · 불안정
- 장점: 제자리 분할로 실전에서 빠른 편
- 한계: 나쁜 pivot 선택은 최악 시간과 깊은 재귀

## 핵심 의사코드

```text
pivot = A[hi]
i = lo
for j in range(lo, hi):
    if A[j] <= pivot:
        A[i], A[j] = A[j], A[i]; i += 1
A[i], A[hi] = A[hi], A[i]
```
