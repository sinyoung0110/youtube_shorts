# 선택 정렬 — 대본 및 검산

- 대상: 처음 배우는 알고리즘 학습자
- 영상 길이: 약 45초
- 핵심 질문: 남은 값 중 가장 작은 것만 앞으로

## 왜 필요한가

매 단계 남은 구간에서 최솟값을 골라 앞에 확정합니다. 비교는 많지만 교환 횟수가 적어 쓰기 비용이 큰 환경에 쓸 수 있습니다.

## 예시와 단계

입력: `[5, 3, 4, 1]`

1. 최솟값 1을 찾아 첫 칸과 교환
2. 남은 [3,4,5]에서 3 선택
3. 차례대로 확정 → [1,3,4,5]

## 특징

- 전제: 앞쪽부터 위치를 확정
- 시간: 최선·평균·최악 O(n²)
- 공간/안정성: 추가 공간 O(1) · 보통 불안정
- 장점: 교환 최대 n−1회
- 한계: 거의 정렬돼도 비교 횟수는 제곱

## 핵심 의사코드

```text
for i in range(n - 1):
    m = i
    for j in range(i + 1, n):
        if A[j] < A[m]: m = j
    A[i], A[m] = A[m], A[i]
```
