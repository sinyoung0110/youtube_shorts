# 장면표

| 장면 | 화면 구성 | 검산 포인트 |
| --- | --- | --- |
| 1. 동기 | 완전 이진 트리 모양의 힙은 배열에 저장되고 부모가 자식보다 큰 성질을 가집니다. 루트 최댓값을 끝으로 보내며 정렬합니다. | 부모 값 ≥ 자식 값인 최대 힙 |
| 2. 예시 | [4, 10, 3, 5, 1] · 단계별 강조 | 10과 끝의 1 교환 |
| 3. 코드 | build_max_heap(A) | 부모 값 ≥ 자식 값인 최대 힙 |
| 4. 정리 | 최선·평균·최악 O(n log n) · 안정적이지 않고 메모리 접근이 흩어짐 | 최선·평균·최악 O(n log n) |
