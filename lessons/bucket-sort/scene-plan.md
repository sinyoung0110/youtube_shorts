# 장면표

| 장면 | 화면 구성 | 검산 포인트 |
| --- | --- | --- |
| 1. 동기 | 값 범위를 여러 버킷으로 나눠 분산하고, 각 버킷 내부를 정렬한 뒤 이어 붙입니다. 값이 고르게 퍼질 때 빠릅니다. | 예시는 값이 [0,1)에 있고 버킷에 고르게 분산된다고 가정 |
| 2. 예시 | [0.42, 0.32, 0.23, 0.52, 0.25] · 단계별 강조 | 0.3대: [0.32] · 0.4대: [0.42] |
| 3. 코드 | buckets = [[] for _ in range(10)]  # 0.1 간격 | 예시는 값이 [0,1)에 있고 버킷에 고르게 분산된다고 가정 |
| 4. 정리 | 균등 분포 기대 O(n + k) · 최악 O(n²) · 분포가 치우치면 한 버킷에서 느려짐 | 균등 분포 기대 O(n + k) · 최악 O(n²) |
