# AVL 트리 — 대본 및 검산

- 대상: 처음 배우는 알고리즘 학습자
- 영상 길이: 약 47초
- 핵심 질문: 한쪽으로 기울어진 BST를 막으려면?

## 왜 필요한가

일반 BST는 삽입 순서에 따라 느려질 수 있습니다. AVL은 각 노드의 높이 차를 제한하고 회전해 탐색 성능을 지킵니다.

## 예시와 단계

입력: `차례로 10, 20, 30 삽입`

1. 10의 오른쪽에 20
2. 20의 오른쪽에 30
3. 왼쪽 회전 → 20이 루트

## 특징

- 전제: 모든 노드의 |왼쪽 높이−오른쪽 높이| ≤ 1
- 시간: 탐색·삽입·삭제 O(log n)
- 공간/안정성: 노드 높이 정보 O(n) · 재귀 스택 O(log n)
- 장점: 최악에도 로그 시간 보장
- 한계: 삽입·삭제 때 높이 갱신과 회전 비용

## 핵심 의사코드

```text
balance = height(left) - height(right)
if balance > 1:
    if key > left.key:
        left = rotate_left(left)
    return rotate_right(node)
if balance < -1:
    if key < right.key:
        right = rotate_right(right)
    return rotate_left(node)
```
