# 장면표

| 장면 | 화면 구성 | 검산 포인트 |
| --- | --- | --- |
| 1. 동기 | 정수의 값 범위가 좁다면 값별 출현 횟수를 세어 바로 순서대로 출력할 수 있습니다. 비교 정렬의 하한을 피하지만 범위가 커지면 낭비가 큽니다. | 정수 키와 감당 가능한 작은 값 범위 |
| 2. 예시 | [4, 2, 2, 1, 3] · 단계별 강조 | 값 순서로 개수만큼 출력 |
| 3. 코드 | lo, hi = min(A), max(A) | 정수 키와 감당 가능한 작은 값 범위 |
| 4. 정리 | 시간 O(n + k) · k=max−min+1 · 값 범위가 크면 시간·메모리 낭비 | 시간 O(n + k) · k=max−min+1 |
