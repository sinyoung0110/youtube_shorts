# 내레이션 (오프라인 음성)

macOS 기본 한국어 음성 Yuna로 생성했습니다. 음성 생성에는 네트워크나 API 키를 사용하지 않았습니다. 구간은 두 영상의 장면 전환에 맞췄습니다.

| 시작 | 내레이션 |
| --- | --- |
| 0.0초 | 숫자 27, 몇 번 만에 찾을까요? |
| 3.7초 | 정렬된 목록에서 가운데부터 확인해요. |
| 7.0초 | 아홉 개의 가운데 23은 27보다 작아요. 왼쪽 절반은 빼고요. |
| 14.0초 | 남은 네 개의 가운데 31은 27보다 큽니다. 오른쪽을 빼요. |
| 21.0초 | 마지막으로 27을 찾았습니다. 세 번 비교했어요. |
| 26.0초 | 범위를 절반씩 줄이는 이진 탐색. 정렬된 목록에 쓸 수 있고, 시간 복잡도는 오 로그 엔입니다. |

원본 오디오 파일은 `remotion/public/audio/narration.wav`입니다.
