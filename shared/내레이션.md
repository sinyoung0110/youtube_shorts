# 이진 탐색 내레이션 (오프라인 음성)

macOS 기본 한국어 음성 Yuna로 만들었습니다. 외부 음성 API나 네트워크 합성은 사용하지 않았습니다.

| 시작 | 대본 |
| --- | --- |
| 0초 | 정렬된 배열에서 9를 찾아볼까요? |
| 4초 | 시작은 로우 0, 하이 5. 미드는 2. A의 2번 값은 3, 목표 9보다 작아요. 로우를 3으로 옮깁니다. |
| 13초 | 남은 범위는 3부터 5. 미드는 4. A의 4번 값 9를 찾아 index 4를 반환해요. |
| 21초 | 로우와 하이는 구간의 양 끝. 로우가 하이 이하인 동안 미드를 계산합니다. 값이 같으면 미드를 반환. 목표보다 작으면 로우를 미드 더하기 1, 크면 하이를 미드 빼기 1로 바꿔요. 범위가 비면 마이너스 1을 반환합니다. |
| 37초 | 범위가 절반씩 줄어 최악은 오 로그 엔. 16개면 최대 다섯 번 확인해요. 첫 미드에서 찾으면 오 원. 빅 오는 정확한 횟수가 아니라 증가율입니다. |
| 48초 | 배열은 로우와 하이 인덱스, BST는 노드의 왼쪽과 오른쪽을 따라가요. 원리는 닮아도 구조는 달라요. |

## 핵심 코드

```python
def binary_search(A, x):
    lo, hi = 0, len(A) - 1
    while lo <= hi:
        mid = (lo + hi) // 2
        if A[mid] == x:
            return mid
        if A[mid] < x:
            lo = mid + 1
        else:
            hi = mid - 1
    return -1
```
