# 이진 탐색: 백만 개 중 원하는 값 찾기

**영상 길이:** 1분 49초 · **화면:** 세로 9:16, 1080×1920 · **음성:** macOS Yuna 오프라인 TTS

## 대본

### 00:00–00:09 · 왜 필요한가
정렬된 기록이 백만 개예요. 하나씩 찾으면 최악엔 백만 번. 더 빠른 방법은 없을까요?

### 00:09–00:19 · 개요
가운데 값과 목표를 비교해요. 목표가 더 크면 왼쪽을 버립니다. 정렬된 전화번호부에서 쓰는 이진 탐색이에요.

### 00:19–00:34 · 예시 1
9를 찾아볼게요. 인덱스는 0부터. 처음 로우 0, 하이 5, 미드 2. A의 2번 값은 3으로 9보다 작아요. 그래서 로우를 미드 더하기 1, 3으로 옮깁니다.

### 00:34–00:45 · 예시 2
남은 범위는 3에서 5. 미드는 4, A의 4번 값이 9. 찾았습니다. 인덱스 4를 반환해요. 가운데를 두 번 확인했어요.

### 00:45–01:12 · 코드
코드에서 로우와 하이는 포함되는 탐색 범위예요. 로우가 하이 이하인 동안 미드를 계산합니다. 같으면 인덱스를 반환. A의 미드 값이 목표보다 작으면 로우를 미드 더하기 1, 크면 하이를 미드 빼기 1로 바꿔요. 범위가 비면 마이너스 1, 검색 실패입니다.

### 01:02–01:18 · Big O
범위는 매번 절반으로 줄어요. 16개는 최악 다섯 번, 백만 개는 스무 번 이내. 최선은 오 원, 평균과 최악은 오 로그 엔. 반복문 추가 공간은 오 원입니다.

### 01:18–01:31 · 장점과 전제
큰 정렬 배열에서 탐색이 빠른 게 장점. 하지만 입력은 미리 정렬되어야 해요. 삽입과 삭제 위치는 오 로그 엔으로 찾아도, 배열을 밀고 당기는 비용은 오 엔일 수 있습니다.

### 01:31–01:40 · 연습
연습. 1, 2, 4, 7, 11, 16, 20에서 16을 찾아보세요. 미드와 경계는 어떻게 바뀔까요?

### 01:40–01:49 · 풀이
첫 미드는 3, 값은 7. 로우를 4로 옮겨요. 다음 미드는 5, 값은 16. 인덱스 5에서 찾고, 가운데 확인은 두 번입니다.

## 핵심 코드 (Python)

```python
def binary_search(A, x):
    lo, hi = 0, len(A) - 1
    while lo <= hi:
        mid = (lo + hi) // 2
        if A[mid] == x:
            return mid
        if A[mid] < x:
            lo = mid + 1
        else:
            hi = mid - 1
    return -1
```

`lo`와 `hi`는 둘 다 포함되는 경계입니다. `lo <= hi`라면 아직 후보가 있고, `lo > hi`가 되면 후보가 없어 `-1`을 반환합니다. 배열은 오름차순 정렬이어야 합니다.

## 예시 계산 검증

찾는 값 `9`, 배열 `A = [-1, 0, 3, 5, 9, 12]`, 인덱스는 0부터입니다.

| 비교 | `lo` | `hi` | `mid = (lo + hi) // 2` | `A[mid]` | 다음 상태 |
| --- | ---: | ---: | ---: | ---: | --- |
| 1 | 0 | 5 | 2 | 3 | `3 < 9`, `lo = mid + 1 = 3` |
| 2 | 3 | 5 | 4 | 9 | 일치, `return 4` |

## 특징과 복잡도

- 정렬된 배열에서만 절반을 안전하게 버릴 수 있습니다.
- 최선 시간: `O(1)` (첫 가운데에서 발견)
- 평균·최악 시간: `O(log n)`
- 반복문 구현의 추가 공간: `O(1)`
- 최악 비교 횟수는 `floor(log₂ n) + 1` 이하입니다. 따라서 16개는 최대 5회, 1,000,000개는 최대 20회입니다. Big O는 정확한 비교 횟수가 아니라 입력 크기에 따른 증가율입니다.
- 장점: 이미 정렬된 큰 배열을 빠르게 검색합니다.
- 한계: 정렬이 전제입니다. 배열에서 삽입할 위치를 찾는 것은 `O(log n)`일 수 있지만, 원소들을 실제로 밀어 자리를 만드는 비용은 `O(n)`일 수 있습니다. 삭제도 이동 비용이 생길 수 있습니다.

## 연습 문제와 풀이

`[1, 2, 4, 7, 11, 16, 20]`에서 `16`을 찾아보세요.

1. `lo=0`, `hi=6` → `mid=3`, 값 `7`. `7 < 16`이므로 `lo=4`.
2. `lo=4`, `hi=6` → `mid=5`, 값 `16`. 인덱스 `5` 반환.

가운데 비교는 총 2회입니다. 영상의 코드, 화면, 음성 예시가 같은 배열·인덱스·경계 업데이트를 사용하는지 확인했습니다.
