# 이진 탐색 쇼츠 대본

**예시:** 정렬 배열 `A = [-1, 0, 3, 5, 9, 12]`, 목표 `x = 9` · 0-based index

정렬된 배열에서 9를 찾아볼까요?

처음은 `lo = 0`, `hi = 5`. `mid`는 `(0 + 5) // 2`, 내림해서 2예요. `A[2]`는 3. 목표 9보다 작으니 `lo`를 `mid + 1`, 즉 3으로 옮겨요.

남은 범위는 3부터 5. `mid = (3 + 5) // 2 = 4`. `A[4]`가 9이므로 index 4를 반환합니다. 가운데 값 확인은 두 번 했어요.

코드에서 `lo`와 `hi`는 탐색 구간의 양 끝입니다. `lo <= hi`인 동안 가운데를 계산해요. 값이 같으면 index를 반환하고, `A[mid] < x`면 `lo = mid + 1`, 그보다 크면 `hi = mid - 1`로 바꿉니다. 구간이 비면 `-1`을 반환해요.

매번 후보 범위가 절반 가까이 줄어듭니다. `16 → 8 → 4 → 2 → 1`. 최선은 첫 가운데에서 찾는 `O(1)`, 평균과 최악은 `O(log n)`입니다. 16개라면 최악에도 가운데 값을 최대 5번 확인해요. Big O는 정확한 횟수가 아니라 입력 크기에 따라 비용이 커지는 정도를 나타냅니다.

배열 이진 탐색은 `lo / mid / hi` 인덱스를 움직입니다. 보내주신 `bst_search`는 트리 노드의 `left / right` 자식으로 내려가는 재귀 BST 검색입니다. 판단 원리는 닮았지만 자료구조와 코드가 다릅니다.

## 학습용 핵심 코드

```python
def binary_search(A, x):
    lo, hi = 0, len(A) - 1
    while lo <= hi:
        mid = (lo + hi) // 2
        if A[mid] == x:
            return mid
        if A[mid] < x:
            lo = mid + 1
        else:
            hi = mid - 1
    return -1
```

### 예시 계산

| 반복 | `lo` | `hi` | `mid = (lo + hi) // 2` | `A[mid]` | 다음 동작 |
| --- | ---: | ---: | ---: | ---: | --- |
| 1 | 0 | 5 | 2 | 3 | `3 < 9`이므로 `lo = 3` |
| 2 | 3 | 5 | 4 | 9 | 찾음, `return 4` |

이 입력에서는 가운데 확인 2회입니다. 임의의 길이 `n`에서 최악 반복 횟수는 `⌊log₂ n⌋ + 1` 이하이며, 점근 시간복잡도는 `O(log n)`입니다. 추가 공간은 반복문 버전 기준 `O(1)`입니다.
